## 🎯 LOGIN FLOW

```
1. User visits http://localhost:3002/admin-login
   ↓
2. Page loads with animations
   - Background starts animating
   - Shapes float
   - Logo bounces
   ↓
3. User enters credentials
   - Email pre-filled: admin@thuto.bac.ac.bw
   - User types password
   ↓
4. User clicks "Login as Super Admin"
   - Button shows loading spinner
   - Backend validates credentials
   ↓
5a. Success:
   - Redirect to /admin
   - Dashboard loads
   - User sees KPI cards and tables
   
5b. Error:
   - Error message appears with shake animation
   - Message displays error details
   - User can try again
```
